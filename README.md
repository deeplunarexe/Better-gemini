# Better Gemini: No Context Overflow

Браузерное расширение для веб-версии Gemini (`gemini.google.com`).

### В чем проблема
В длинных диалогах веб-чат Gemini начинает забывать, о чем шла речь в начале: теряет контекст, стек технологий, код и договоренности.

### Что делает расширение
Следит за количеством сообщений. Каждые 15 сообщений (число можно изменить) оно берет историю из чата, делает краткую выжимку и незаметно подмешивает её в следующий запрос.

В самом чате ничего лишнего не появляется — вы видите только свой обычный текст, а модель снова помнит весь диалог.

---

### Установка (1 минута)

1. Открой в браузере: `chrome://extensions` (или `edge://extensions`).
2. Включи **«Режим разработчика»** в правом верхнем углу.
3. Нажми **«Загрузить распакованное расширение»**.
4. Выбери папку:
   ```
   (путь к папке с рашсирением)
   ```
5. Открой [gemini.google.com](https://gemini.google.com/app) и обнови страницу (F5).

---

### Как пользоваться

* Просто общайся в Gemini как обычно.
* Вверху появится кнопка `⚡ BGS • 🧠 0/15` со счетчиком сообщений. Её можно перетащить мышкой в любое место.
* Для каждого нового чата счетчик автоматически сбрасывается в 0.
* Когда наберется 15 сообщений, расширение спросит, обновить ли память (можно включить авто-режим, чтобы не спрашивало).
* Клик по кнопке открывает настройки: там можно поменять частоту обновления (от 5 до 30) или нажать «Обновить контекст прямо сейчас».
